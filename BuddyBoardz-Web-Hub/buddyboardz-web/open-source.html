WHAT OPEN MEANS HERE
01
Inspectable logic

Core scoring and prioritisation rules should be understandable and testable.

02
Local-first records

The v1 app stores working records on the student's device. There is no account-based cloud sync in the current scope.

03
Honest limitations

Offline behaviour, backup responsibility, browser storage limits, and blueprint sources should be explained clearly.

04
Small surface area

No unnecessary server, login layer, tracking feed, or AI chat wrapper in v1.

PRIVACY, IN PLAIN LANGUAGE

Your study records are yours
to look after.

Where data lives

The current product specification uses IndexedDB in the browser to store settings, sessions, mistakes, and simulator state locally.

What this means

Clearing browser data, changing devices, or storage eviction can affect records. Export a backup and keep it somewhere you control.

What v1 does not include

No user accounts, server-side database, or cloud synchronisation are included in the current v1 scope.

This page describes the intended v1 architecture. Publish a final privacy notice only after verifying the deployed app, hosting configuration, analytics, and any third-party requests.
